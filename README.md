# Gent Apparel BD 👖✨

> **"Better Quality, Better Style!"** — 100% Authentic Export Clothing & Denim E-Commerce Platform.

Official Online Store for **Gent Apparel BD** ([Facebook](https://www.facebook.com/gentapparelbd)), featuring authentic export surplus menswear, premium denim jeans, knitwear sweaters, tailored chinos, and athletic joggers.

---

## 🌟 Key Features

- **⚡ Modern Tech Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Framer Motion.
- **🛍️ Complete E-Commerce Workflow**:
  - Filterable Catalog & Search (Category, Size, Price range)
  - Interactive Size Guide Modal (Jeans & Outerwear measurements)
  - Quick View Modal & Lightbox Image Gallery
  - Persistent Cart Drawer & Wishlist (Zustand + LocalStorage)
  - Multi-step Checkout with Cash on Delivery (COD), bKash, and Nagad
  - Dynamic Shipping Calculations (Inside Dhaka ৳80, Outside Dhaka ৳150)
  - Real-time Order Tracking (`GA-2026-XXXXX`)
- **📱 Responsive & Luxury UI/UX**:
  - Jet Black (`#0A0A0A`), Tailoring Gold (`#C8A265`), and Denim Navy color palette
  - Roman Serif + Clean Sans-serif Typography
  - Floating WhatsApp Concierge (`01560-018131`) & Facebook Messenger integration
- **🛡️ Resilient Architecture**:
  - Prisma Database Proxy Engine with seamless fallback catalog for demo and offline modes
  - Zero-config deployment readiness

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
